Information Dispersal Algorithm: a sentence is split into n fragments, and any m of them rebuild it.

Parameters (set <parameter>=<value>):
  n=4                 number of fragments generated
  m=2                 number of fragments needed to rebuild the sentence
  field=galois        galois: GF(2^8); prime: integers modulo 257
  fragments=0,3       the m fragments used to rebuild the sentence, from 0 to n-1
  detail=results      results: the main matrices; all: every intermediate step

Commands:
  help                shows this help
  exit                closes the console (also Ctrl-D)

Any other line is a sentence to encode and decode: its characters must have a code from 0 to 255.
